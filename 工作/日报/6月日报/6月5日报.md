## crm部署遇到的问题
### 1、shell 执行 source update_mysql.sql 提示 No such file or directory
- 问题：source update_mysql.sql命令报错找不到文件
- 原因：source 是 bash 环境变量加载命令，不能用来执行 mysql 脚本；
混淆 shell 命令与 mysql 导入语法
- 解决：改用 mysql 客户端导入，
- mysql -h127.0.0.1 -uphoenix -peeemlphPXQIOPZ2 -Dphoenix （登录 mysql 内使用source 文件名.sql）
- source 文件名
