## 2.理解各个job作用

## 2.1 首次初始化：GLOBLE_update_jenkins_config
### 刷新 Jenkins 站点的基础配置，包括系统描述信息、全局凭证、权限管理、Jenkins 系统级参数等（与具体业务无关，是 Jenkins 环境初始化的基础操作）。
## 2.2 认证信息生成：ERP_basic_auth
### 生成 H6 各业务应用的接口认证信息（如 basic-auth 凭证），这些认证信息会被后续应用部署时调用，是应用间接口访问鉴权的基础。
## 2.3 刷新部署 Job：GLOBLE-update-jenkins-jobs
### 根据修改后的 toolset 配置（jenkins 分支、erp 分支、develop 分支），自动生成 / 刷新 ERP 核心流水线 Job，包括：
- ERP_db_deploy_int：数据库初始化部署任务
- ERP_app_deploy_int：业务应用容器部署任务
## 2.4业务部署核心 Job
### ERP_db_deploy_int
#### 作用：完成 Oracle 数据库的初始化部署，包括 hd40 用户重建、表空间分配、业务库表初始化、JDBC 连接串配置生效等，解决 “数据库用户异常、下拉配置缺失” 等问题，为应用部署提供可用的数据库环境。
### ERP_app_deploy_int
#### 作用：基于 Docker 容器部署 ERP 所有业务应用（如 hdpos4-dist、panther-dts-server、h6-crm-service 等），拉取指定版本镜像、配置容器端口 / 资源、接入 Apollo 配置中心，最终启动所有业务服务。
## 2.5业务部署核心 Job
### GLOBLE_deploy_nginx
#### 作用：部署 Nginx 网关 配置域名、反向代理、路由、负载均衡

###  1.docker安装失败
#### 解决方法：改用国内镜像源安装 Docker

#### 步骤：先删除之前添加的官方源
```angular2html
rm -f /etc/yum.repos.d/docker-ce.repo
```

##### 添加国内镜像源
```angular2html

cat > /etc/yum.repos.d/docker-ce.repo <<EOF
[docker-ce-stable]
name=Docker CE Stable - \$basearch
baseurl=https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/centos/8/\$basearch/stable
enabled=1
gpgcheck=1
gpgkey=https://mirrors.tuna.tsinghua.edu.cn/docker-ce/linux/centos/gpg
EOF
```
#### 清理并重建缓存
```angular2html
dnf clean all
dnf makecache

```

#### 安装 Docker
```angular2html
dnf install -y docker-ce docker-ce-cli containerd.io docker-compose-plugin
```

#### 启动并设置开机自启
systemctl enable --now docker

#### 验证安装
```angular2html
docker --version
systemctl status docker
```
