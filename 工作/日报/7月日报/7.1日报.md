# 今日工作

## 1、业务背景：线下三大产品共用负载均衡  
线下 ERP、CRM、RWS 三套测试环境共用阿里云负载均衡，依靠域名转发区分业务；常规发布监听 80 端口 
端口转发 + Nginx 80→443 重定向
##  2、负载均衡核心配置流程（四层 TCP / 七层 HTTP/HTTPS）
###  2.1后端虚拟服务器组（核心绑定后端 ECS）
###  2.1.1用途：绑定后端应用 ECS 实例，定义后端服务真实端口，支持多台 ECS 挂载并配置权重分发流量
###  2.1.2业务端口示例：
- License 服务后端端口：9080； 
- Windows 远程桌面后端端口：3389； 
- Linux SSH 后端端口：22；

###  2.1.3配置要点

- HTTP 服务默认关闭健康检查
- 多台同业务 ECS 填入相同后端端口，通过权重实现负载分发
- 不同业务创建独立虚拟服务器组隔离。

###  2.2前端监听（公网访问入口，前后端口分离）

###  2.2.1协议区分规则

- http TCP 四层协议：Linux SSH、Windows 远程桌面等远程连接场景；
- HTTP/HTTPS 七层协议：ERP/CRM/RWS 网页应用，HTTPS 需绑定域名证书，安全性更高；
###  2.2.2 端口设计关键逻辑

- 前端监听端口自定义（对外访问端口，公网访问使用）；
- 后端端口固定（ECS 内服务真实运行端口，不可随意修改）；
- 示例：前端监听 60502，后端 SSH 真实端口 22，外部访问公网IP:60502即可连通；

###  2.2.3域名转发复用 80 端口：
同一 80 监听端口通过不同 ServerName 区分多个域名，转发至不同后端服务器组，无需占用多个 80 端口

##  3、阿里云 VPC 内网与公网互通核心组件
阿里云整体业务运行在VPC 私有网络（内网网段：10、172、192），
内网资源默认无法直接访问互联网，外部也无法直连 VPC 内 ECS，
依靠三类组件打通网络：


### 3.1.外部访问阿里云（公网入流量）

- 私网型负载均衡：本身无公网能力，必须绑定弹性公网 EIP才能对外暴露；
- 公网型负载均衡：自带绑定 EIP，IP 不可解绑复用；
- 弹性公网 IP（EIP）：可灵活绑定负载均衡、NAT 网关、单台 ECS，支持解绑迁移，推荐生产使用。

### 3.2阿里云访问外部互联网（内网出流量）

#### 3.2.1 SNAT（NAT 网关）：VPC 内网 ECS 统一出口网关，所有服务器访问外网统一走 NAT 网关，绑定 EIP 作为固定出口 IP；
 
#### 3.2.2 作用：解决内网无公网 IP 服务器拉取制品、调用第三方系统的外网访问需求。

### 3.3 内网互通访问控制（ECS、RDS互通）
#### 3.3.1 安全组：ECS 层面内网访问白名单，限制指定 IP / 网段通行；
RDS 数据库独立白名单：仅添加单台 ECS 内网 IP，禁止开放全网段（0.0.0.0/0 存在安全风险）；
规范：内网服务通信统一使用内网私网地址，不开启 RDS、ECS 公网地址。



### 4、ECS 云服务器规范
#### 4.1操作系统规范
- 应用服务 ECS：Rocky Linux 9.7；
- 数据库 ECS：Rocky Linux 8.x；
#### 4.2机器规格配比：主流 1:2（4 核 8G）、1:4、1:8，无 4 核 64G 等非常规机型；
#### 4.3带宽：单 ECS 自带 200M 带宽，高并发场景选用公网型负载均衡扩容带宽。


### 5、跨两套私域网络互通（公司内网 ↔ 阿里云 VPC）
#### 5.1互通前提：两端均需固定公网 IP；
#### 5.2白名单双向配置：
- 阿里云侧：安全组 / 负载均衡访问控制添加公司 SNAT 出口 IP；
- 公司侧：安全策略添加阿里云负载均衡 EIP；
#### 5.3安全规范：禁止全网段放行，仅添加固定出口单点 IP，避免公网暴露风险（如 Jenkins、SSH 不直接开公网）。


###  6.常见排障思路
#### 6.1.ECS 访问数据库不通：优先排查安全组白名单、RDS 内网白名单，确认两端同 VPC 内网互通；
#### 6.2.ECS外部无法访问阿里云服务：检查负载均衡 EIP 绑定、前端监听协议 / 端口、负载均衡访问控制白名单；
#### 6.3.阿里云服务器无法拉取外网制品：检查 NAT 网关 SNAT 规则、绑定的 EIP 出口 IP；
#### 6.4.远程桌面 / SSH 连不上：核对 TCP 监听端口、后端 ECS 对应远程端口、安全组放行规则。

###  7、核心要点精简
#### 7.1.负载均衡前后端口解耦，前端对外自定义、后端服务端口固定；
#### 7.2.内网走 VPC 私网地址，进出互联网分别靠 EIP、SNAT 网关；
#### 7.3.内外网互通必须双向白名单，最小权限放行单点 IP，杜绝全网开放；
#### 7.4.TCP 用于远程连接，HTTP/HTTPS 用于 Web 业务，80 端口可多域名复用；
#### 7.5.线下 ERP/CRM/RWS 共用负载均衡，靠域名区分业务流量。
