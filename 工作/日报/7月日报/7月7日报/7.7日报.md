 # ERP 系统整体部署架构

## 一、架构总览

ERP 系统部署于阿里云（杭州地域），整体采用**单 VPC 私有网络 + 公网 SLB 接入**的架构。所有业务组件以 Docker 容器化方式运行在 ECS 云服务器上，通过 OpenResty 反向代理网关统一对外提供服务，由 Jenkins 自动化流水线驱动 CI/CD 全流程。
