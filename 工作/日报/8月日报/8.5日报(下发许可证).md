## 10.7.119.114
###  1. 宿主机上进入工作目录并查看
```
cd /hdapp/heading/license-server_production/
ll
```
### 2. 进入 Docker 容器查看许可证文件位置

```
docker exec -it 10.7.119.114_license-server_production sh
```
###  在容器内执行：
```
ls                     # 查看根目录文件
cd ../lickit-server/   # 进入许可证目录
ls                     # 确认 hdlicenses.xml 存在
exit                   # 退出容器
```
### 3. 宿主机上创建 config 目录并拷贝文件出来
```
mkdir config
cd config
docker cp 10.7.119.114_license-server_production:/opt/lickit-server/hdlicenses.xml ./
```
### 4. 查看拷贝出来的文件内容（验证）

```
ls
cat hdlicenses.xml
```

### 5. 生成 SSH 密钥（为后续免密登录做准备）
```
ssh-keygen          # 一路回车即可（默认无密码）
cat ~/.ssh/id_rsa.pub   # 查看公钥，后续可添加到目标服务器
```
