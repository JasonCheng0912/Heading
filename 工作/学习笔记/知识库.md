## 端口映射

### 概念

端口映射是将宿主机（物理机/虚拟机）的端口与容器内部端口建立绑定关系，使外部流量能通过宿主机端口访问到容器内运行的服务。

### Docker 端口映射

#### 基本命令

# -p 宿主机端口:容器端口
```bash
docker run -d -p 8080:8080 --name myapp myimage
```
# 映射多个端口
```bash
docker run -d -p 8080:8080 -p 8443:8443 --name myapp myimage
 
```

### 用户访问完整链路（端口视角）

```
用户浏览器(80/443)
  → SLB 负载均衡(监听端口 80/443)
    → OpenResty 网关(hdpos.conf 路由规则)
      → upstream.conf(转发到后端服务器 IP:端口)
        → 宿主机端口(如 8080)
          → Docker 容器端口映射(8080:8080)
            → Java 微服务内部监听端口(8080)
```

### 关键配置文件

#### OpenResty upstream 配置示例
```nginx
upstream hdpos_service {
    server 172.16.0.61:3xxxx 
}
```

#### Docker Compose 端口映射
```yaml
services:
  hdpos-service:
    image: hdpos:latest
    ports:
      - "8080:8080"      # 业务端口
      - "5005:5005"      # 远程调试端口
  redis:
    image: redis:7
    ports:
      - "16379:6379"     # 宿主机16379→容器6379
```

### 常见业务端口对应关系

| 组件 | 宿主机端口 | 容器端口 | 说明 |
|------|-----------|---------|------|
| Nginx/OpenResty | 80/443 | 80/443 | 网关入口 |
| Redis | 16379 | 6379 | 缓存服务 |
| MySQL/RDS | 3306 | 3306 | 数据库 |
| Jenkins | 8080 | 8080 | CI/CD |
